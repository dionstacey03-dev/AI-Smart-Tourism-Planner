# 🇱🇰 CeylonAI — AI Smart Tourism Planner

A modern smart tourism planning prototype designed to help travelers create personalized journeys across Sri Lanka based on their trip duration, budget, interests, number of travelers, and preferred travel style.

CeylonAI explores how intelligent software can make travel planning simpler, more personalized, and easier to understand.

---

## ✨ Features

- Personalized Sri Lanka itinerary generation
- Day-by-day travel plans
- Multiple travel interests:
  - Nature & Adventure
  - Culture & Heritage
  - Beaches & Relaxation
  - Wildlife
  - Food & Local Experiences
- Adjustable trip duration
- Traveler count selection
- Budget levels
- Travel pace preferences
- Starting location selection
- Estimated trip budget breakdown
- Destination showcase
- Responsive mobile navigation
- Loading and itinerary generation states
- Responsive design for desktop, tablet, and mobile

---

## 🧠 How It Works

The current version uses a rule-based planning system implemented in React.

Traveler preferences are collected through the trip planner and used to select suitable destinations and generate a structured day-by-day itinerary.

This version is a portfolio prototype and does not currently use a live AI model.
